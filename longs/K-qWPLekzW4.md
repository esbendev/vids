## descripción:

En este video, les presento la nueva versión de hyprland, que trae importantes cambios, incluyendo el uso de Lua para los archivos de configuración. Si bien los archivos .conf seguirán funcionando, los .lua tendrán precedencia, marcando una evolución en este tiling window manager. Les guiaré a través de las novedades para que su hyprland setup esté siempre actualizado, y como siempre, dejo todos los links en la descripción para este linux tutorial.

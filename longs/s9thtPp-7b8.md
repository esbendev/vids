# ¡Estos navegadores corren en tu terminal! 

[ver el video](https://www.youtube.com/watch?v=s9thtPp-7b8)

## descripción:

En este video, exploramos los navegadores que se ejecutan directamente desde la terminal, buscando opciones para nuestro arch linux. Desde los más simples hasta los que permiten ver videos, esta inmersión en el web browser desde la línea de comandos es ideal para los entusiastas del cli. ¡Descubre qué terminal web browser es el mejor para tus necesidades!

## comandos usados

### para instalar los navegadores
Lynx
```bash
sudo pacman -S lynx ​
```

Links
```bash
sudo pacman -S links ​
```

w3m
```bash
sudo pacman -S w3m ​
```

ELinks
```bash
sudo pacman -S elinks ​
```
